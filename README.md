# Neuroliq

Neuroliq — исследовательский проект по представлению и обработке знаний на основе развивающегося графа концептов.

Это исследовательский проект: его модели и методы предстоит проверять экспериментами. На этапе M1 реализовано минимальное графовое ядро на Python: концепты с непрозрачными UUID и нетипизированные числовые связи в памяти. Активация и маршрутизация отсутствуют; постоянное хранилище и математические методы обработки графа не выбраны. AGI не является заявленной целью.

Актуальное состояние проекта описано в [`docs/current-state.md`](docs/current-state.md).
Фундаментальные принципы собраны в [`docs/foundation.md`](docs/foundation.md).

Установка, проверка контракта M1 и вывод детерминированного искусственного графа (Python 3.11+):

```text
python -m pip install -e ".[test]"
python -m pytest tests/test_graph.py tests/test_package.py -q
python -X utf8 -m neuroliq.fixture
```

Минимальный API и границы реализации описаны в [`docs/architecture.md`](docs/architecture.md). Диагностические метки fixture находятся вне модели концептов.
