## Гипотезы, ограничения и отрицательные результаты

| Гипотеза | Итог |
| --- | --- |
| H1: выбранное минимальное соседство достаточно | Опровергнуто ролями, identity и values |
| H2: выбранный ordered ConceptId route достаточно | Опровергнуто identity/value/scope; расширенный язык маршрута не исследован |
| H3: выбранная композиция сохраняет контрольные различия | Поддержана только в ограниченном срезе; общая выразительность/индукция не доказана |
| H4: обученный вход экономичнее без потери ответов | Поддержана при стабильной статистике; устойчивость к shift опровергнута |
| Выращивание универсальной смысловой основы | Не подтверждено: авторские данные и ручные концепты/контракты |
| Операционная семантика Python | Отрицательный результат: v1 не исполняет state/binding |

Python-проба `x=0; if x==0: x=1` сохраняет source, вручную ожидаемый переход x:0→1 и фактический отказ попытки создать неподдерживаемый assign. Отсутствуют binding, численное равенство, изменение состояния. IF над proposition не становится интерпретатором. `eval`/`exec` или готовый интерпретатор для доказательства не использовались; проба по смыслу не пройдена.

Ограничения: ручные позиции и 11 концептов; два предмета/шесть имён; конечная грамматика, без общей морфологии, аспектов, кванторов, логического вывода, концептного слияния/разделения. Alpha-канонизация не нормализует логическую эквивалентность/коммутативность all. Null и неизвестное value не различены. Имена не определяют identity; местоимение требует явного binding, неоднозначный текст отвергается. Политика оптимизирует точный поиск, не реализует универсальное рассуждение. Смысл из нетипизированных связей не подтверждён. Graph/L0/Workbench не менялись.

## Воспроизведение

Из корня ветки в PowerShell в существующем окружении:

```powershell
$env:PYTHONUTF8 = '1'
python -m neuroliq.autonomous run --output data/autonomous-reproduction
python -m neuroliq.autonomous query --memory data/autonomous-reproduction/demo/memory.json --request data/autonomous-reproduction/demo/query.json --policy data/autonomous-reproduction/learning.json --output data/autonomous-reproduction/answer.json
python -m pytest -q
```

Без `--policy` query использует fixed; `--visits 1` демонстрирует отказ. Запрос уже формализован, результат построен из памяти и evidence. Исходный текст не передаётся отдельному ответчику; LLM отсутствует во всём пути. Воспроизводятся данные/ответы, но не побитовые времена.

Отдельное минимальное окружение: Python 3.13.2 и [requirements-lock.txt](../../experiments/autonomous-prototype-01/requirements-lock.txt):

```powershell
python -m venv data/autonomous-venv
& data/autonomous-venv/Scripts/python.exe -m pip install -r experiments/autonomous-prototype-01/requirements-lock.txt
& data/autonomous-venv/Scripts/python.exe -m pip install --no-deps --no-build-isolation -e .
$env:PYTHONUTF8 = '1'
& data/autonomous-venv/Scripts/python.exe -m neuroliq.autonomous run --output data/autonomous-reproduction-clean
$tests = @(Get-ChildItem tests/test_autonomous_*.py)
& data/autonomous-venv/Scripts/python.exe -m pytest -q $tests.FullName
```

Lock — только CLI/его тесты; полный существующий web/research regression требует прежних optional dependencies. В текущем окружении выполнены все 279 тестов. Инструкции установки выше не выполнялись в исследовательском запуске.

## Остановка и нерешённые вопросы

Остановка по 12.4.1/4 контракта: конечный срез выполнен, независимых данных для проверки выращивания основы нет, расширение не отвечает на текущую гипотезу. Pivot не использован. Новый научный подход требует новых свидетельств; увеличение шума или исправление regex не заменяет их. Это завершённый ограниченный/отрицательный результат, не объявление общего успеха по тестам.

Открыто: индукция концептов/контрактов из independently annotated RU/EN; критерий сравнения индуцированного смысла с ручным baseline; необходимость новых структурных примитивов; адаптация к shift без test leakage; исполнимые state/binding конструкции; NL fidelity на реальных независимо размеченных источниках. Эти задачи не реализованы в текущем цикле.

Полный список изменённых файлов — [changed-files.txt](../../experiments/autonomous-prototype-01/changed-files.txt). Решения — ADR 001/002, условия опытов — EXPERIMENTS. Git хранит историю checkpoint; итоговый push выполнен в экспериментальную ветку без merge.
