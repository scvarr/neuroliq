# Формат экспериментальной композиции v1

Содержание — JSON `{entities, root}`. Участник объявляется локальным адресом и содержит непрозрачный UUID концепта, скалярное value (null означает неизвестное значение), опционально стабильный адрес origin. Узел — `{ref: адрес}`, `{unknown: true}` либо `{concept: UUID, args: [...]}`. Корень выражает proposition. Проверяются ссылки, число/типы позиций, отсутствие лишних полей/неиспользованных объявлений, глубина 16 и 256 узлов. Известное `null` отдельно от неизвестного пока не выражается: это ограничение v1.

Каталог v1 содержит 11 ручных концептов: человек, книга, ключ, передача, наблюдение, убеждение, отрицание, прошлое, возможность, условие, совместное содержание. Адреса стабильны (UUID5), аннотации для человека/адаптера. Ядро не извлекает смысл из подписи: проверяет контракт result/positions. Контракт give = (human,item,human), see = (human,human), think = (human,proposition); остальные операторы принимают proposition. Они задают содержательные различия вручную. Это небольшой явный формальный язык, не автоматически выращенная основа.

Канонизация переименовывает локальные адреса в r0, r1… по первому использованию и сохраняет value, origin, концепты и вложенность. Перестановка позиций применения смыслозначима. Порядок записей all сохраняется, но не утверждает время событий; семантически коммутативная перестановка all не нормализуется. Канонизация гарантируется относительно alpha-переименования локальных адресов, а не произвольной логической эквивалентности. Совпадение имён людей не объединяет объявления.

Модификаторы — вложенные применения, поэтому not(all(A,B)) отличается от all(not(A),B), а think(участник,A) не даёт утверждения A в родительской области. Истинность мира не следует из структурной корректности. Контекст/provenance хранится внешней записью памяти; surface не участвует в semantic signature.

Неподдерживаемые явления: количественные кванторы, общая логика, измерения/единицы, интерпретация Python, автоматическая семантическая индукция и неоднозначность общего языка. Не расширять грамматику ради видимости покрытия.

## Память v1

Snapshot содержит один concepts-каталог, дерево contexts и records. Контекст имеет parent/mode (source/belief/hypothesis/abstract); принадлежность области не утверждает истинность. Запись содержит scene, context, provenance, status (accepted/proposed), kind (observation/abstract), split. Accepted означает принятую интерпретацию авторского источника, а не проверенную истину реального мира. Каждый source сохраняет language/text/interpretation (authored/resolved/ambiguous). Неоднозначное evidence требует proposed.

Повторный участник может иметь origin `record:rN`, проверяемый по уже существующему объявлению concept/value. Это адрес записи и локального канонического участника, а не глобальный концепт конкретного имени. Ссылка сохраняется при JSON round-trip. Циклические origin в v1 не допускаются; рекурсия контекстов диагностируется. Неявного coreference по имени нет. Вложенная область включается в область запроса только явным режимом descendants.

Наблюдение схем удаляет значения и origin из принятой alpha-формы train, считает повторения и сохраняет support. Минимум два наблюдения создают candidate, без принятия нового концепта, слияния имён или утверждения конкретного события. Это ограниченная статистика композиции уже размеченных данных, не MDL-факторизация сырого текста. Абстрактная запись хранится отдельно по kind и не должна извлекаться как наблюдённый факт. Snapshot проверяется целиком при загрузке и атомарно сохраняется; ≤1 000 записей и ≤100 MiB.
