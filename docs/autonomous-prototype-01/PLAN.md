# План Autonomous Prototype 01

Исходная точка: `a0e197ae93f4203ed03b66d6d66e370fb5dd21b3`, ветка `research/autonomous-prototype-01`. Основание — [контракт](../neuroliq-autonomous-research-contract.md) и задание пользователя от 09.10.2026. Изолированный CLI-эксперимент; существующие Graph, L0 и Workbench не меняются.

## Конечные этапы

| Этап | Цель и проверяемый результат | Завершение и минимальная валидация |
| --- | --- | --- |
| P0 | Ресурсы, пределы, план и состояние продолжения | Чистая исходная ветка, инструменты доступны, документация, diff-check, commit/push |
| P1 | Ограниченный обзор и 2–4 гипотезы | Первичные источники, условия данных, контрпримеры и кандидаты описаны |
| P2 | Сравнение трёх моделей на критических различиях | Исполняемое сравнение, измерения и один ADR выбора |
| P3 | Формальная композиция и канонизация | Роли, значения, ссылки, вложенность; положительные и отрицательные проверки |
| P4 | Переиспользуемая основа и контекстная память | Сохранение/загрузка, области, provenance, межобластные ссылки; проверка изоляции |
| P5 | Ограниченный RU/EN адаптер | Парафразы и новые комбинации; round-trip и явные отказы вне грамматики |
| P6 | Самостоятельная ограниченная навигация | Формальный запрос, baseline, trace, ресурсный отказ и отвлекающие данные |
| P7 | Адаптация выбора вычислительного пути | Реальные параметры до/после, train/validation/test по сценам, контроль качества и стоимости |
| P8 | Канонические токены и будущий корпус | Обратимость, версия словаря, экспорт с split/provenance без обучения Transformer |
| P9 | Финальный сквозной эксперимент | Групповые метрики, Python-контрастная проба, ограничения, итоговый отчёт, commit/push |

Каждый этап заканчивается validation → documentation → `git diff --check` → commit → push. Следующий этап начинается после успешного push. При остановке точная операция записывается в STATUS. Новая итерация требует новой гипотезы; один допустимый pivot, максимум две последовательные коррекции провала.

## Ресурсные пределы (абсолютные)

- Загрузки: максимум 100 MiB суммарно; в первом срезе — без моделей/корпусных архивов.
- CPU: максимум 30 минут суммарного процессорного времени экспериментальных запусков; один запуск ≤60 секунд стендового времени. GPU: 0 минут.
- RSS одного экспериментального процесса ≤512 MiB, записанные артефакты ≤100 MiB.
- Данные: до 1 000 конструкций, до 500 запросов, глубина композиции ≤16, до 256 узлов на конструкцию.
- Навигация: до 1 000 посещений/запрос, до 16 шагов пути, таймаут ≤1 секунды/запрос; отказ диагностируется.
- Обучение: один первичный цикл до 5 проходов; до двух диагностированных коррекций, без подбора по test.
- Первичное сравнение: три представления, два варианта навигации. Никаких платных API, секретов и изменений main.

Исчерпание лимита означает сохранённый отрицательный/частичный результат и остановку. Малый контролируемый авторский корпус проверяет механизмы, но не доказывает автоматическое выращивание концептов из реальных многоязычных наблюдений.
