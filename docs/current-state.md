# Текущее состояние

Этап: M6.2 выполнен — воспроизводимый raw-text graph baseline наблюдаемых текстовых форм и соседств, не semantic L0; стенд M4.1 — единый Docker-запускаемый Neuroliq Graph Lab. Roadmap M0–M8 не изменён.

M6.2 остаётся последним выполненным экспериментом. [Построение скелетного L0](l0-skeleton-construction-hypotheses.md) фиксирует только направление следующего исследовательского этапа: временный нефакторизованный surface graph → факторизованный нетипизированный L0 возможных смысловых переходов → будущие направленные наблюдения/маршруты, статистика, контекст и динамика. Ближайший фокус — достаточно внятный скелетный L0 до возвращения к динамическим маршрутам; в него не входят порядок конкретного текста, направленная статистика, runtime path или динамическое состояние. Допустима разрушительная замена surface-форм переиспользуемыми компонентами без заранее назначенных грамматических категорий и с сокращением вспомогательного словаря. Факторизация, автоматическое выделение скрытых компонентов и межъязыковое совпадение не подтверждены; алгоритм, критерий принятия и окончательная структура словаря не выбраны. Код и результаты экспериментов не менялись.

- Core M1 (`Graph`, `Concept`, `Connection`) и математика Activation M2 не изменены. Концепт содержит только UUID; связи нетипизированные, технически неориентированные. Self-loop и дубликаты запрещены.
- M6.2: отдельный `src/neuroliq/m6_2.py` строит Graph из локальных UTF-8 `.txt`: NFC, поверхностные Unicode L/N/M-токены с внутренними `-`, `'`, `’`, `_`, identity после casefold, punctuation как узлы. Один ключ переиспользует ConceptId, повторное/обратное соседство — одну Connection с техническим фиксированным strength=1.0. Частоты и self-pair считаются вне Graph; документы не соединяются. CLI выдаёт checkpoints по числу вхождений (default 10_000/100_000/1_000_000/10_000_000), дельты и обязательный final с частотами/degree/top-N без UUID. На маленьком fixture: 38 вхождений, 27 узлов, 34 связи, 11 повторов узлов, 2 повтора связей, 1 self-pair; 60 targeted/core tests прошли. [Контракт, диагностика и ограничения M6.2](m6-2-experiment.md). Это сырой baseline форм, не представление смысловых знаний; NLP/LLM, merging, occurrence/RouteBundle, routing, обучение strength и production ingestion отсутствуют, масштаб большого корпуса не проверен.
- Введён отдельный `ExperimentDefinition`: версия JSON, title, концепты с UUID и внешними labels, connections/strength, seeds и параметры. Loader валидирует документ и сохраняет идентичность UUID; save/load возвращает эквивалентное описание. Runtime/trace в файл не входят.
- Единственный `neuroliq.web:app` предоставляет Graph Lab: создание/редактирование/удаление структуры, seeds и параметров, импорт/экспорт JSON, start/step/run/reset, текущую activation, ranking/contributions/full trace выбранного шага. JavaScript только редактирует описание и отображает результаты Python.
- Успешная замена definition целиком строит новый Graph и пустой Activation; старый trace уничтожается. Ошибка валидации оставляет прежнее состояние. Mutating API ради редактора в Graph не добавлен.
- Один контейнер FastAPI и статический frontend, внешний настраиваемый localhost-порт. Серверного хранилища и многопользовательских сессий нет; эксперимент переносится файлом.

Запуск из корня:

```text
docker compose up --build
```

Открыть [Graph Lab](http://127.0.0.1:17890). Порт задаётся `NEUROLIQ_PORT`, default 17890; binding `127.0.0.1:${NEUROLIQ_PORT:-17890}:8000`. Остановка: `docker compose down`.

Формат файла, ручной round-trip, воспроизведение M3/M4 и targeted tests: [Graph Lab](graph-lab.md). Архитектура: [описание](architecture.md).

Проверка M4.1: 75 targeted tests прошли; Docker image собран, localhost binding и изменение host port подтверждены compose-конфигурацией. В браузере выполнены создание графа, скачивание JSON, очистка и импорт файла с сохранением UUID/strength/seeds/параметров, Step/Run и все три сценария M3/M4 с просмотром истории.
