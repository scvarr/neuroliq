# Текущее состояние

Этап: M1 — минимальное графовое ядро реализовано.

Состояние:
- Python-пакет предоставляет `Graph`, `Concept`, `ConceptId` и `Connection`;
- граф существует только в памяти и хранит постоянную структуру концептов и связей;
- концепт содержит только непрозрачный UUID; человеческие метки находятся вне core-модели;
- связь содержит два ConceptId и конечную числовую `strength`, без семантического типа;
- граф технически неориентированный в пределах M1; self-loop и повторная связь одной пары запрещены;
- доступны создание и получение концептов и связей, чтение соседей и перечисление структуры;
- детерминированный fixture содержит пять концептов и четыре связи; диагностический snapshot сортируется по UUID и использует внешние метки;
- targeted tests проверяют инварианты графа, ошибки без изменения структуры и воспроизводимость диагностики;
- активация, маршрутизация, поиск пути, затухание, рабочий подграф, языковой слой, постоянное хранилище, MCP и LLM отсутствуют.

Воспроизведение после `python -m pip install -e ".[test]"`:

```text
python -m pytest tests/test_graph.py tests/test_package.py -q
python -X utf8 -m neuroliq.fixture
```

Принятые фундаментальные ограничения:
- смысл концепта определяется структурой графа;
- связь не имеет семантического типа;
- числовая сила связи допустима;
- конкретная математика силы и маршрутизации не определена;
- язык отделяется от смыслового графа.

Неориентированность M1 — техническое ограничение текущей реализации, а не окончательное фундаментальное решение. Диапазон и семантическая интерпретация силы связи не зафиксированы. M1 подтверждает работу структурного API, но не проверяет гипотезы об активации или извлечении смысла.
