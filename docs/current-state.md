# Текущее состояние

Этап: M4 — проверено двухшаговое структурное пересечение на контролируемом fixture через неизменную активацию M2 поверх ядра M1.

Состояние:
- `Graph`, `Concept`, `ConceptId` и `Connection` хранят постоянную структуру в памяти; core-модель M1 не изменена;
- концепт содержит только непрозрачный UUID; человеческие метки находятся вне core-модели;
- связь содержит два ConceptId и конечную числовую `strength`, без семантического типа;
- граф технически неориентированный; self-loop и повторная связь одной пары запрещены;
- отдельный `Activation` хранит временное отображение `ConceptId → activation`, параметры запуска и trace каждого шага;
- один или несколько seeds задаются явно; следующий шаг суммирует `source_activation * strength * decay`, затем оставляет до `max_active` кандидатов по убыванию activation, при равенстве — по возрастанию UUID;
- retention отсутствует; `max_steps` ограничивает число переходов после step 0; reset удаляет activation, параметры и историю trace;
- порядок source и target детерминирован; trace содержит sources, все переходы с множителями, суммы candidates, kept и pruned;
- отдельный M2 fixture имеет пять концептов и шесть положительных связей; исходный M1 fixture не изменён;
- отдельный deterministic M3 fixture имеет пять концептов СТОЛИЦА, ФРАНЦИЯ, ПАРИЖ, ЛОНДОН, ЛИОН и ровно четыре нетипизированные связи с одинаковым strength=1.0;
- при decay=0.5, max_active=5, max_steps=1 одиночные seeds оставляют ПАРИЖ в ничьей с ЛОНДОНОМ либо ЛИОНОМ (0.5); совместные seeds делают ПАРИЖ уникальным лидером (1.0 против 0.5) через сумму двух contributions;
- M3 web-наблюдатель предоставляет три кнопки контролируемых запусков, таблицы кандидатов и вкладов; формула M2 и pruning policy не изменены;
- локальный FastAPI web-наблюдатель показывает M2 fixture, принимает seeds и параметры, команды «Сброс», «Шаг», «Выполнить»; выбранный концепт показывает текущую activation, выбранная связь — persistent strength;
- браузер отображает полученные activation и trace; всю вычислительную динамику выполняет Python;
- targeted tests проверяют неизменность графа, формулу, aggregation, pruning, multi-seed, детерминизм, reset, параметры и web-команды;
- отдельный deterministic M4 fixture: A—C—X—D—B, C—E, D—F; семь концептов и шесть нетипизированных связей strength=1.0;
- при decay=0.5, max_active=7, max_steps=2 одиночные A/B оставляют X в ничьей 0.25, совместные дают X=0.5 против остальных 0.25 через два вклада C→X и D→X; обратная волна C→A/D→B сохранена, pruning отсутствует;
- M4 web-наблюдатель воспроизводит три сценария; общий экран позволяет просмотреть ranking, contributions и JSON trace каждого шага, вычисления остаются только в Python;
- отдельный механизм извлечения ответа, маршрутизация, retention/context memory, обучение, языковой слой, persistence, MCP и LLM отсутствуют; M3/M4 подтверждают только структурное пересечение и зависимость ранжирования от seeds на контролируемых fixtures.

Воспроизведение после `python -m pip install -e ".[test,web]"`:

```text
python -m pytest tests/test_m4.py tests/test_m3.py tests/test_activation.py tests/test_graph.py tests/test_package.py tests/test_web.py -q
python -X utf8 -m neuroliq.m4_fixture
python -X utf8 -m neuroliq.m3_fixture
python -X utf8 -m neuroliq.m2_fixture
python -X utf8 -m neuroliq.fixture
```

Запуск M4-наблюдателя:

```text
python -m uvicorn neuroliq.web:m4_app --host 127.0.0.1 --port 8004
```

Открыть [http://127.0.0.1:8004](http://127.0.0.1:8004). Нажать A, B, A + B; счётчики 7/6. «Просмотр шага» показывает таблицы и исходный trace step 0, 1, 2. Итоговые значения X: 0.25 в обоих одиночных запусках (ничья), 0.5 в совместном (уникальный лидер). 48 targeted tests прошли; три сценария и история шагов вручную проверены в браузере. Полные traces и ограничения: [эксперимент M4](m4-experiment.md). Подтверждено только двухшаговое структурное пересечение на этом графе; рассуждение, универсальная маршрутизация и критерий всего первого цикла не подтверждены.

Запуск M3-наблюдателя:

```text
python -m uvicorn neuroliq.web:m3_app --host 127.0.0.1 --port 8003
```

Открыть [http://127.0.0.1:8003](http://127.0.0.1:8003). Нажать по очереди «СТОЛИЦА», «ФРАНЦИЯ», «СТОЛИЦА + ФРАНЦИЯ»: каждая кнопка начинает независимый запуск с одинаковыми параметрами и одним шагом. Счётчики — 5/4, отсечений нет. Таблицы и JSON trace показывают, что лидерство ПАРИЖА возникает из вкладов СТОЛИЦА → ПАРИЖ и ФРАНЦИЯ → ПАРИЖ по 0.5. Полные результаты и ограничения: [эксперимент M3](m3-experiment.md). Понимание и универсальная маршрутизация не подтверждены; критерий всего первого исследовательского цикла не выполнен этим экспериментом.

Запуск M2-наблюдателя:

```text
python -m uvicorn neuroliq.web:app --host 127.0.0.1 --port 8000
```

Открыть [http://127.0.0.1:8000](http://127.0.0.1:8000). Статические файлы и Cytoscape.js включены в Python-пакет. По умолчанию выбраны seeds А=1 и Б=1, decay=0.5, max_active=2, max_steps=3. «Шаг» создаёт step 0 и выполняет первый переход; следующие нажатия продолжают текущую волну. «Выполнить» завершает оставшиеся переходы. Изменение формы начинает новый запуск при следующей команде. «Сброс» очищает runtime, сохраняя значения формы для нового запуска.

Для ручной проверки: счётчики 5/6; первый шаг оставляет В=0.75 и Г=0.25, отсекает Д=0.25; второй оставляет А=0.4375 и Б=0.1875; выполнение до третьего оставляет В=0.265625 и Г=0.109375. Выбор концепта показывает activation, связи — strength. Повторный шаг после лимита не меняет состояние. Сброс убирает временную activation и trace. Zoom/pan, перетаскивание и «Вписать граф» меняют только вид страницы.

Полный воспроизводимый trace и интерпретация ограничений: [эксперимент M2](m2-experiment.md). Baseline — инструмент наблюдения распространяющейся волны, а не подтверждённая модель Neuroliq, механизм контекста или маршрутизатор. Roadmap не изменён. Неориентированность остаётся техническим ограничением; семантика силы связи и окончательная математика не определены.
