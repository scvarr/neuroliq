# ADR-001: нетипизированные взвешенные рёбра

- **Статус:** принято как исследовательская гипотеза
- **Этап:** M0

## Решение

Базовое ребро смыслового графа не несёт семантического типа. Оно выражает только наличие связи между концептами и может иметь числовую силу.

## Мотив

Семантика должна возникать из структуры окружающего подграфа и динамики работы с ним, а не храниться в имени отношения.

## Последствия и границы

Это исследовательская гипотеза, которая может быть пересмотрена по результатам экспериментов. Ориентированность рёбер этим решением не определяется.
