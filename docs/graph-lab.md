# Neuroliq Graph Lab

Graph Lab, введённый в M4.1, — единый редактор и наблюдатель Activation M2. Этот документ описывает запуск, формат файла и пользовательскую процедуру. API и lifecycle реализации — в [architecture.md](architecture.md); текущая фаза проекта — в [current-state.md](current-state.md).

## Запуск

Из корня проекта с установленным Docker Desktop:

```bat
docker compose up --build
```

Открыть [Graph Lab](http://127.0.0.1:17890). Остановить:

```bat
docker compose down
```

Один контейнер FastAPI/uvicorn обслуживает Python API и статический frontend. Внутренний порт 8000; внешний задаёт `NEUROLIQ_PORT`, по умолчанию 17890. Binding только localhost. Например, в Windows cmd.exe:

```bat
set "NEUROLIQ_PORT=17891"
docker compose up --build
```

Либо создать `.env` рядом с compose.yaml со строкой `NEUROLIQ_PORT=17891`. Тогда открыть `http://127.0.0.1:17891`. Ручной uvicorn для обычной работы не требуется.

## Формат *.neuroliq.json

Отдельное [лексическое ревью](lexical-workspace.md) доступно по `/lexical` и ссылке в шапке. Оно хранит батчи и решения в SQLite (`./data` через Compose); Graph Lab по-прежнему использует переносимый JSON и временный runtime. Форматы и состояния этих двух инструментов независимы.

UTF-8 JSON, версия 1, строго следующие поля:

```json
{
  "format_version": 1,
  "title": "Пример",
  "concepts": [{"id": "00000000-0000-0000-0000-000000000001", "label": "А"}],
  "connections": [],
  "run": {
    "seeds": {"00000000-0000-0000-0000-000000000001": 1.0},
    "decay": 0.5,
    "max_active": 10,
    "max_steps": 2
  }
}
```

Связь содержит только `concept_a`, `concept_b` (UUID существующих концептов) и `strength` (конечное число). Пара неориентированная; дубликаты пары независимо от порядка концов и self-loop запрещены. UUID уникальны и сохраняют идентичность при загрузке; метки — внешние строки, допустимы одинаковые и пустые. Семантического типа ребра нет.

Seeds ссылаются на существующие UUID; activation конечная и неотрицательная. Пустой набор допустим в описании, но Activation требует хотя бы один seed при запуске. decay — конечное число от 0 до 1, max_active — целое >=1, max_steps — целое >=0. Булевы значения, числовые строки, NaN/inf, неизвестные поля, версия и ссылки, повторные JSON-ключи отклоняются. Strength допускает отрицательные числа согласно Graph; существующий M2 отклоняет их при запуске.

Сохранение и загрузка обеспечивают эквивалентный round-trip с сохранением UUID, labels, strength, seeds и параметров. Порядок массивов и ориентация концов в документе сохраняются, хотя Graph канонизирует пару. Форматирование JSON и исходное текстовое написание UUID/чисел не являются частью definition. Runtime, activation по шагам, trace и позиции узлов в файл не входят.

## Работа в интерфейсе

«Новый пустой» очищает эксперимент. Укажите метку и нажмите «Добавить концепт»: UUID создаётся автоматически и виден под меткой. Метку можно изменить; удаление концепта убирает его связи и seed. В разделе связей выберите существующие концы, strength и добавьте связь; силу можно изменить, связь удалить.

Отметьте seeds, задайте activation и параметры. Изменение activation включает концепт в seeds. Все изменения полей применяются после выхода из поля. Успешная запись целиком пересоздаёт Graph и пустой Activation, включая изменения меток/параметров. Ошибка записи не заменяет предыдущий подтверждённый эксперимент.

«Начать (шаг 0)» заново задаёт seeds. «Шаг» выполняет один переход; «Выполнить» завершает до max_steps; обе команды начинают запуск автоматически из пустого runtime. «Сброс» очищает только временное состояние. Переключатель шага показывает ranking, contributions и полный JSON trace, не меняя текущую activation узлов.

«Сохранить JSON» скачивает текущий подтверждённый эксперимент. Для проверки round-trip сохраните, нажмите «Новый пустой», затем загрузите этот файл через «Загрузить .neuroliq.json». Альтернативный импорт — JSON в раскрываемом поле. Некорректный документ оставляет предыдущее состояние.

## M3/M4

Загрузите `experiments/m3-simple-retrieval.neuroliq.json`: 5/4, совместные seeds уже заданы. «Выполнить» даёт ПАРИЖ=1.0, ЛОНДОН=ЛИОН=0.5. Отключите ФРАНЦИЯ и повторите: ПАРИЖ=ЛОНДОН=0.5; затем включите ФРАНЦИЯ, отключите СТОЛИЦА: ПАРИЖ=ЛИОН=0.5. Восстановление обоих seeds возвращает совместный результат.

Загрузите `experiments/m4-two-step-bridge.neuroliq.json`: 7/6. Совместные A/B дают X=0.5 и A=B=E=F=0.25 на шаге 2. Только A даёт A=X=E=0.25, только B — B=X=F=0.25. Шаги 0, 1, 2 и обратные вклады доступны в trace. Эти числа — контрольные ожидания для процедуры; исследовательские выводы и полные таблицы сохранены в [M3](m3-experiment.md) и [M4](m4-experiment.md).

## Проверка

Для разработки: `python -m pip install -e ".[test,web]"`, затем:

```bat
python -m pytest tests/test_experiment.py tests/test_m3.py tests/test_m4.py tests/test_activation.py tests/test_graph.py tests/test_package.py tests/test_web.py -q
git diff --check
```

Docker build и ручной flow проверяются через команды запуска/остановки выше. Состояние общего локального стенда исчезает при перезапуске; сохраняйте JSON перед остановкой.
