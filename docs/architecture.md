# Архитектура

На этапе M0 архитектура вычислительного ядра не определена. Тип хранилища пока не выбран. Язык реализации не должен диктовать архитектуру.

Известен только базовый принцип: концепты образуют смысловой граф, а связи между ними не имеют семантического типа и могут иметь числовую силу. Все остальные архитектурные решения определяются экспериментами.
