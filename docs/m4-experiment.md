# Эксперимент M4: двухшаговый мост

Проверяемая гипотеза: структурное пересечение сохраняется через промежуточные концепты, и общий удалённый X становится уникальным лидером после двух propagation step на неизменной математике M2. Это ограниченная проверка числового ранжирования на искусственном графе.

## Структура и параметры

Отдельный `build_m4_fixture()` в `src/neuroliq/m4_fixture.py` создаёт семь концептов и ровно шесть неориентированных нетипизированных связей:

```text
A -- C -- X -- D -- B
     |         |
     E         F
```

Связи: A—C, C—X, X—D, D—B, C—E, D—F. Все persistent `strength=1.0`. E и F — симметричные отвлекающие листья у промежуточных концептов; дополнительной поддержки X они не дают. A и B не связаны с X напрямую. Два независимых маршрута A→C→X и B→D→X имеют длину 2 и пересекаются только в X. Метки внешние; фиксированные UUID с `int` от 301 до 307 соответствуют A, B, C, D, X, E, F и служат воспроизводимости и сортировке ничьих.

Три запуска используют один Graph и один сбрасываемый runtime: A=1.0; B=1.0; A=B=1.0. Параметры одинаковы: `decay=0.5`, `max_steps=2`, `max_active=7`. После step 0 выполняются два propagation. Каждый переход передаёт `source_activation * strength * decay`; candidates суммируют contributions. Retention отсутствует. Все candidates сохранены, `pruned=[]` на каждом шаге. Лимит 7 равен полному числу концептов; увеличение до 100 даёт идентичные traces и activation. При равенстве порядок UUID не означает уникального лидерства.

| --- | --- |
| 0 | A=1.0, B=1.0 |
| 1 | C=0.5, D=0.5 |
| 2 | X=0.5, A=0.25, B=0.25, E=0.25, F=0.25 |

| Шаг | Source → target | source_activation | strength | decay | contribution |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | A → C | 1.0 | 1.0 | 0.5 | 0.5 |
| 1 | B → D | 1.0 | 1.0 | 0.5 | 0.5 |
| 2 | C → A | 0.5 | 1.0 | 0.5 | 0.25 |
| 2 | C → X | 0.5 | 1.0 | 0.5 | 0.25 |
| 2 | C → E | 0.5 | 1.0 | 0.5 | 0.25 |
| 2 | D → B | 0.5 | 1.0 | 0.5 | 0.25 |
| 2 | D → X | 0.5 | 1.0 | 0.5 | 0.25 |
| 2 | D → F | 0.5 | 1.0 | 0.5 | 0.25 |

В одиночном A максимум делят A, X и E (0.25); в одиночном B — B, X и F (0.25). В совместном X=0.5 уникально превышает A, B, E, F (по 0.25). Его activation восстанавливается через оба шага:

```text
A=1.0 → C=0.5 → вклад в X=0.25
B=1.0 → D=0.5 → вклад в X=0.25
X = 0.25 + 0.25 = 0.5
```

Других contributions в X нет. Удвоенная общая seed activation увеличивает сигнал, но относительное лидерство объясняется топологией: X получает два вклада, каждый конкурент — один. Одиночные результаты показывают, что одного маршрута недостаточно для уникального лидерства.

## Обратная волна

На втором propagation присутствуют C→A и D→B. В одиночных запусках возвращённая activation seed равна activation X и листа. В совместном обратная волна даёт A=B=0.25 и не препятствует X=0.5. Возвраты не фильтруются. X ещё не является source в пределах двух шагов: переходы X→C/D потребовали бы третьего propagation, который здесь не исследуется. Эксперимент не исправляет циклы, не вводит память пути, visited/refractory state или запрет обратного хода. Более глубокая динамика и устойчивость лидерства не проверены.

## Воспроизведение

После `python -m pip install -e ".[test,web]"`:

```text
python -X utf8 -m neuroliq.m4_fixture
python -m pytest tests/test_m4.py tests/test_m3.py tests/test_activation.py tests/test_graph.py tests/test_package.py tests/test_web.py -q
git diff --check
python -m uvicorn neuroliq.web:m4_app --host 127.0.0.1 --port 8004
```

Открыть [web observer M4](http://127.0.0.1:8004). Счётчики — 7/6. Нажать A, B и A + B: каждая кнопка восстанавливает одинаковые параметры, задаёт seeds и выполняет start/run через Python API. «Просмотр шага» позволяет проверить rankings, contributions и JSON trace step 0, 1, 2 после каждого запуска; граф и сведения выбранного узла показывают текущее итоговое состояние runtime. Просмотр истории не выполняет вычисления и не меняет runtime. Ручные команды «Шаг», «Выполнить», «Сброс» сохранены. M2 и M3 доступны через прежние приложения.

Проверено 6 октября 2026: 48 targeted tests прошли; `git diff --check` без ошибок. Все три сценария вручную воспроизведены кнопками web observer; шаги 0, 1, 2 просмотрены через переключатель, rankings и contributions совпали с таблицами. Тесты проверяют точную структуру, равные strength, отсутствие прямых A—X/B—X, два маршрута, полные contributions с возвратами, неизменность Graph и соседства между всеми запусками/reset, повторяемость и независимость от порядка создания структуры и seeds. Сравнение max_active=7 и 100 подтверждает отсутствие влияния pruning.

## Исследовательский вывод

Подтверждена ограниченная гипотеза: на этом deterministic fixture структурное пересечение через C и D сохраняется на втором шаге; X становится уникальным лидером через aggregation двух независимых путей при одинаковых strength и неизменной формуле M2. Вычисления и обратная волна полностью наблюдаемы. Activation и Graph не изменялись; новый маршрутизатор не создавался.

Не подтверждены рассуждение, смысл промежуточных концептов, универсальная маршрутизация, перенос на другие графы, выбор глубины/остановки, устойчивость на циклах или более длинных путях. Структура искусственная и мост задан при построении. Retention/context memory, обучение, persistence, языковой слой, LLM и MCP не реализованы.

Это частичная проверка первого исследовательского цикла: продемонстрированы изменение ранжирования при смене seeds на фиксированном графе и объяснимость двухшагового вычисления. Осмысленные промежуточные структуры, существенно меньший рабочий подграф на большом графе и объективное сравнение маршрутизаторов здесь не проверены. Критерий всего цикла не выполнен. Roadmap не расширен.
