## Численное объяснение

На шаге 1 A и B дают C=D=1.0×0.5=0.5. На шаге 2 каждый из C/D отправляет по 0.25 всем трём соседям. X суммирует два вклада: 0.25+0.25=0.5; A, B, E, F получают по 0.25.

На шаге 3 разрешённые обратные переходы восстанавливают промежуточные концепты:

```text
C = A×0.5 + X×0.5 + E×0.5 = 0.125 + 0.25 + 0.125 = 0.5
D = B×0.5 + X×0.5 + F×0.5 = 0.125 + 0.25 + 0.125 = 0.5
```

Таким образом, состояние O={C=D=0.5} переходит в Q={X=0.5, A=B=E=F=0.25}, а Q возвращается в O. Шаги 4..6 фактически повторяют эти переходы. O≠Q, поэтому минимальный период равен 2, а не 1. Из детерминированности неизменного перехода и равенств O→Q→O следует продолжение этого режима при дальнейшем применении той же формулы; эксперимент выполняет только шаги 0..6.

Decay уменьшает каждый отдельный вклад, но не гарантирует уменьшения суммы в target: несколько возвратов компенсируют уменьшение. За два шага C получает собственную возвращённую поддержку через A/E/X величиной 3×0.5×0.5×C=0.75C и поддержку D через X величиной 0.25D. Аналогично D'=0.25C+0.75D. При C=D=0.5 обе суммы точно восстанавливают 0.5.

Незатухание относится к повторяющимся фазам: максимум после шага 0 равен 0.5, сумма колеблется между 1.0 и 1.5. Сумма не сохраняется и не обязана монотонно убывать. Все наблюдаемые числа — двоичные дроби, точно представимые float; равенство проверено без допуска. Совпадают состояния и rankings, но полный trace шага 1 отличается от 3/5 по sources и transitions. У 2/4/6 и 3/5 вычислительное содержимое trace повторяется, кроме номера шага.

X лидирует только в чётной фазе, а в нечётной отсутствует среди candidates. Эхо возникает на графе без структурных циклов: техническая неориентированность допускает повторные проходы туда и обратно по тому же ребру. Здесь подтверждено воспроизводимое числовое эхо, а не память контекста или универсальное свойство графов. Activation/Graph, decay и max_active не подбирались; альтернативные механизмы и M5.2+ не исследовались.

## Воспроизведение и validation

В Graph Lab загрузить `experiments/m5-1-backwave-echo.neuroliq.json`, нажать «Выполнить» и последовательно просмотреть шаги 0..6. Запуск стенда и формат файла описаны в [Graph Lab](graph-lab.md). Исполнение через Python из корня проекта с установленными зависимостями:

```python
from pprint import pprint
from neuroliq.activation import Activation
from neuroliq.experiment import ExperimentDefinition

definition = ExperimentDefinition.load("experiments/m5-1-backwave-echo.neuroliq.json")
graph, labels = definition.build()
runtime = Activation(graph)
runtime.start(**definition.run.model_dump())
runtime.run()
pprint(runtime.snapshot())
```

Targeted validation:

```text
python -m pytest tests/test_m5_1.py -q
git diff --check
```

Результат: 3 targeted tests прошли. Проверены точное соответствие концептов/UUID/связей/strength M4 и фиксированный контракт M5.1, save/load с воспроизведением вычисления, полные rankings и contributions шагов 0..6, суммы вкладов, источники и отсутствие pruning, точные равенства фаз и различие соседних фаз. Независимые загрузки и шесть последовательных step дают тот же полный snapshot, что run. Структура и соседство Graph остаются неизменными. Полный suite не запускался: runtime и loader не менялись, исследовательский результат проверен непосредственно через существующий Activation.
