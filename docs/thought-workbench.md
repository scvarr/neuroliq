# Ручной Thought Workbench

Страница `/thought-workbench` открывается из Graph Lab, lexical review и постоянного L0. Запуск: `python -m uvicorn neuroliq.web:app --host 127.0.0.1 --port 8000`. Общая локальная SQLite по умолчанию — `data/lexical-workspace.sqlite3`; другой файл задаётся `NEUROLIQ_WORKSPACE_DB`. Restart с тем же путём сохраняет данные.

Workbench редактирует один переиспользуемый semantic graph и сохраняет мысли как ordered routes непосредственно по ConceptId. Это минимальный исследовательский baseline, не окончательная архитектура Thought Program. Concrete scene/value representation остаётся открытым вопросом; отдельные local occurrences и literal/value nodes не моделируются.

## Ручная процедура

1. Нажмите «Новый концепт», введите подсказку и сохраните. Непрозрачный UUID создаётся независимо от текста. Создайте, например, HUMAN и SEE. Каталог поддерживает поиск по подсказке/ID и редактирование выбранной annotation.
2. В блоке «Глобальная связь» выберите HUMAN и SEE, нажмите «Добавить общую связь». HUMAN—SEE — одна нетипизированная неориентированная связь, общая для всех thoughts. Она не задаёт semantic role или направление мысли. Перестановка концов не создаёт вторую связь.
3. Создайте исходный фрагмент с неизменённым текстом и необязательным context. Сохраните его; источник может переиспользоваться несколькими мыслями.
4. Нажмите «Новая мысль», выберите источник, задайте annotation и сохраните. Пустой route допустим как черновик.
5. В «Добавить существующий ConceptId» выберите HUMAN, затем SEE, затем HUMAN, каждый раз нажимая «Добавить шаг в конец маршрута». Получится `[HUMAN, SEE, HUMAN]` с одним HUMAN в каталоге. Повторный шаг — повторный ConceptId в последовательности; отдельной сущности участия нет. Для выбора можно искать в каталоге или кликнуть на узел графа.
6. Выберите шаг для удаления или перестановки кнопками «раньше»/«позже». Все соседние шаги должны иметь глобальные связи; невалидное изменение отклоняется и оставляет сохранённый route прежним. Самосвязь позволяет повторить один ConceptId подряд, если это нужно исследователю.
7. Создайте вторую мысль, например с route `[SEE, HUMAN]`. Переключение мысли показывает её маршрут и подсветку на том же общем графе, сохраняя все вершины и глобальные связи.
8. Используемый концепт, источник или связь нельзя удалить, пока ссылки не убраны. Удаление мысли сохраняет общий graph и source. Изменения annotation/source подтверждайте кнопкой сохранения перед переключением записи или другой операцией.

Серые линии показывают общую топологию, оранжевые — связи выбранного route. На узлах видны все номера посещений, на связях — номера переходов. Отдельная запись `[1] HUMAN → [2] SEE → [3] HUMAN` явно сохраняет направление и порядок. Номера не являются slots/roles. Человеческие annotations не определяют вычислительную семантику ConceptId. Layout строится заново после загрузки.

## Обмен и внешний review

«Экспорт полного JSON» скачивает snapshot версии 2: полный каталог annotations, глобальные connections, исходные text/context, мысли с source_id, annotation и route. Передайте файл в новый ChatGPT-сеанс вместе с исследовательским вопросом: скрытого состояния для чтения нет.

Для импорта выберите snapshot и нажмите «Импортировать snapshot». Это заменяет весь Workbench; перед заменой сохраните нужный экспорт. Сервер валидирует весь документ до записи, ошибка сохраняет прежнее состояние. Graph Lab, L0 и lexical workspace не затрагиваются. Одинаковые ID, топология и маршруты дают одинаковые канонические байты; export → import → export точен. Порядок каталогов незначим, порядок и повторы route значимы.

При открытии прежней незамерженной schema Workbench её данные уничтожаются и создаются четыре новые `tw_*` таблицы без переноса. Старые snapshots версии 1 отклоняются; совместимость не поддерживается. Это разрешённая destructive replacement текущего milestone, не механизм будущих миграций.

Контракт — [architecture.md](architecture.md#persistent-manual-thought-workbench). Ограничения: один ручной локальный graph, route — линейная последовательность, layout не сохраняется, при совместном редактировании одной записи побеждает последняя запись. Конкретные сцены/значения, грамматика, semantic edge types, layers, language adapter и reasoning/runtime не определены.
