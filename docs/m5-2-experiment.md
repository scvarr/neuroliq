# Эксперимент M5.2: направленная динамика прохождения

Результат: ограниченная гипотеза подтверждена на неизменной топологии M5.1. Symmetric control точно воспроизводит незатухающий период 2. Asymmetric traversal сохраняет уникальное лидерство X на шаге 2, но уменьшает соответствующие фазы вдвое каждые два шага. Фактические значения всех шагов 0..6 совпали с предсказанием без допуска; это точно представимые двоичные дроби.

## Контракт и граница реализации

Единственный источник структуры — `experiments/m5-1-backwave-echo.neuroliq.json`, загружаемый существующим ExperimentDefinition. UUID int=301..307 соответствуют A, B, C, D, X, E, F. Топология A—C—X—D—B, C—E, D—F: 7 концептов, 6 неориентированных нетипизированных связей; все persistent strength=1.0. Seeds A=B=1.0, decay=0.5, max_active=7, max_steps=6 одинаковы для двух сценариев.

Отдельный пакетный эксперимент `src/neuroliq/m5_2.py` читает публичный API Graph и явное отображение `(source, target) → route_weight`. Для каждой существующей Connection обязательны оба независимых коэффициента; отсутствующие направления, лишние пары и неконечные/отрицательные коэффициенты отклоняются. Коэффициенты не записываются в Graph, Connection или ExperimentDefinition.

Формула только экспериментального M5.2:

```text
contribution = source_activation * connection.strength * route_weight(source -> target) * decay
```

Существующий Activation M2 не изменён. Его публичный start/snapshot используется только для валидации параметров и seed trace шага 0; propagation выполняется отдельно. Sources и соседи упорядочены по UUID, contributions суммируются в этом порядке, candidates ранжируются по убыванию activation и UUID при ничьей. Предыдущая activation не сохраняется. Каждый transition диагностирует source, target, source_activation, strength, route_weight, decay, contribution; шаг содержит sources, агрегированные candidates, kept/pruned. Новый lifecycle runtime, API Graph Lab и формат experiment-файла не вводятся.

| Направление | Symmetric control | Asymmetric traversal |
| --- | ---: | ---: |
| A→C, B→D | 1.0 | 1.0 |
| C→A, D→B | 1.0 | 0.5 |
| C→X, D→X | 1.0 | 1.0 |
| X→C, X→D | 1.0 | 0.5 |
| C→E, D→F | 1.0 | 1.0 |
| E→C, F→D | 1.0 | 0.5 |

## Фактические полные traces

В таблицах UUID заменены внешними метками. Rankings и transitions приведены в порядке фактического trace; sources перечислены по UUID. Для всех candidates kept=true; kept содержит все ID в порядке ranking, pruned=[] на каждом шаге обоих сценариев. На step 0 sources и transitions пусты. Отсутствующие концепты не входят в candidates текущего шага.

## Численное объяснение

Symmetric control совпадает с полным snapshot M5.1 после удаления только дополнительного поля route_weight=1.0 из transitions. На шагах 1/3/5 C=D=0.5; на 2/4/6 X=0.5 и A=B=E=F=0.25. Возвраты C=A×0.5+X×0.5+E×0.5=0.125+0.25+0.125=0.5 (аналогично D) восстанавливают фазу. Состояния разных фаз различаются, поэтому минимальный период равен 2.

В asymmetric сценарии шаг 1 по-прежнему даёт C=D=0.5. На шаге 2 X получает два вклада по 0.25: X=0.5. E/F получают по 0.25, а A/B по 0.125 из-за route_weight=0.5. Структурное пересечение M4 сохраняется: X уникально превышает каждого конкурента.

На шаге 3 обратная поддержка ослаблена:

```text
C = A×1.0×0.5 + X×0.5×0.5 + E×0.5×0.5
  = 0.0625 + 0.125 + 0.0625 = 0.25
D = B×1.0×0.5 + X×0.5×0.5 + F×0.5×0.5
  = 0.0625 + 0.125 + 0.0625 = 0.25
```

Для нечётной фазы двухшаговое преобразование равно C'=0.375C+0.125D, D'=0.125C+0.375D: собственные возвраты через A/E/X дают по 0.125C, а поддержка D через X — 0.125D. При C=D фаза умножается на 0.5. Линейность фиксированного перехода и отсутствие pruning дают такое же масштабирование следующей чётной фазы. На шагах 3/5 C=D=0.25/0.125; X на шагах 2/4/6 равен 0.5/0.25/0.125. Фактические соответствующие состояния различаются, поэтому незатухающего периода 2 здесь нет. Чередование состава активных узлов и обратные переходы сохраняются.

Уменьшение относится к соответствующим фазам, а не к монотонности суммы соседних шагов: суммы asymmetric равны 2.0, 1.0, 1.25, 0.5, 0.625, 0.25, 0.3125. Шаги 0..6 выполнены; геометрическое продолжение следует из указанного фиксированного линейного перехода в симметричном по C/D состоянии.

## Воспроизведение и targeted validation

Из корня с установленными зависимостями проекта:

```text
python -m neuroliq.m5_2
python -m pytest tests/test_m5_1.py tests/test_m5_2.py -q
git diff --check
```

CLI выводит JSON с labels и обоими полными snapshots; можно передать путь к исходному файлу M5.1 позиционным аргументом. В выводе сохранены UUID, параметры, источники, все transitions с route_weight, ранжированные candidates и kept/pruned шагов 0..6. Graph Lab продолжает исполнять только M2; воспроизведение M5.2 выполняется отдельной командой.

Результат: 6 targeted tests прошли (3 существующих M5.1 и 3 M5.2). Проверены полное точное совпадение symmetric с M2, независимые численные эталоны asymmetric sources/transitions/candidates всех шагов, суммы contributions, уникальный лидер X, коэффициент 0.5 между соответствующими фазами, повторяемость, отсутствие pruning, точная топология/strength/параметры и неизменность концептов, связей и соседства исходного Graph. Одна Connection остаётся тем же объектом при перестановке концов. Отдельная проверка отклоняет неполную/лишнюю таблицу направлений и некорректные route weights. Полный suite не запускался: core, loader и web не изменены.

## Исследовательский вывод и ограничения

Подтверждено только следующее: на фиксированном искусственном графе и заданных коэффициентах независимая динамика прохождения по направлениям существующих неориентированных связей сохраняет двухшаговое пересечение и заменяет незатухающее эхо геометрическим уменьшением фаз. Расхождений с предсказанием нет. Это проверенная ограниченная исследовательская гипотеза, не принятое общее архитектурное решение Neuroliq и не универсальный алгоритм маршрутизации.

Directed Graph, изменение persistent strength, обучение/подбор коэффициентов, route statistics/evidence storage, probability normalization, context-dependent routing, visited/refractory state, другие decay, pruning/width experiments, M6 ingestion и решения M5.3+ не исследовались. Roadmap не расширен; критерий всего первого исследовательского цикла остаётся невыполненным.
