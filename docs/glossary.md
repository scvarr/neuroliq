# Словарь

Определения ниже рабочие и могут уточняться по мере экспериментов.

- **Концепт** — элемент смыслового графа; его смысл рассматривается в контексте окружающей структуры.
- **Смысловой граф** — исследуемое представление концептов и связей между ними.
- **Связь** — факт связи между концептами без семантического типа.
- **Сила связи** — допустимое числовое значение, связанное с ребром; его математика пока не определена.
- **Подграф** — часть графа, рассматриваемая отдельно.
- **Активный подграф** — рабочее обозначение подграфа, участвующего в некотором процессе обработки; точное определение предстоит исследовать.
- **Маршрутизация** — исследуемый процесс перемещения или выбора пути по графу; конкретный метод не определён.
- **Гипотеза** — проверяемое предположение, на котором строится эксперимент.
