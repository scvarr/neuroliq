# Контракт описания эксперимента

Документ задаёт шаблон проверяемого исследовательского отчёта. Канонический список выполненных экспериментов находится в [навигаторе](README.md); второй индекс здесь не ведётся.

В описании эксперимента указываются:

- **ID**
- **Название**
- **Гипотеза**
- **Исходные данные**
- **Параметры**
- **Процедура**
- **Ожидаемое наблюдение**
- **Фактический результат**
- **Вывод**
- **Статус**

Исходные данные, параметры и процедура должны позволять воспроизвести проверку. Фактический результат следует отделять от ожидания, а вывод — ограничивать условиями эксперимента. Укажите диагностические артефакты, команды с явным shell для shell-specific синтаксиса и фактическую validation. Последующие гипотезы не меняют исторические результаты отчёта.
