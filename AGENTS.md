# Рабочий контракт Neuroliq

- Пользовательский интерфейс, документация, комментарии, описания решений и сообщения ведутся на русском языке. Английский допускается в техническом синтаксисе, именах библиотек, API, идентификаторах и общепринятых элементах исходного кода.
- Перед задачей читай только документацию, относящуюся к текущему этапу.
- Не сканируй весь репозиторий без необходимости.
- Первая точка входа для понимания состояния проекта — `docs/current-state.md`.
- После `docs/current-state.md` читай [навигатор документации](docs/README.md) и выбирай только релевантные задаче документы.
- Архитектурные решения читай, только если они относятся к текущей задаче.
- Не вводи новую архитектуру без необходимости текущего ограниченного этапа.
- Не сохраняй legacy без явного требования.
- Исследовательские реализации можно удалять и заменять.
- Важные вычислительные механизмы должны быть наблюдаемыми и диагностируемыми.
- Не придавай ребру смыслового графа семантический тип без отдельного принятого архитектурного решения.
- Не используй LLM для скрытой подмены исследуемого алгоритма.
- Каждая задача должна иметь ограниченную и проверяемую область изменений.
- После существенного принятого этапа обновляй `docs/current-state.md`.
- Не превращай документацию в журнал мелких изменений.
- Git history хранит историю изменений; документация — только актуальную архитектуру, решения и исследовательские выводы.
